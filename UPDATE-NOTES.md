# Colourful SEO Portfolio — V3

Updated identity and copy using the supplied SEO portfolio: about, experience, services, case studies, skills, writing and contact. The provided 3+ years, 15+ clients and 40+ articles are retained; no new ranking or traffic numbers were invented.

Visual changes: persistent cyan/violet/magenta/gold nebula backdrop; brighter planetary materials and lighting; transparent WebGL background; lighter overlays; readable coloured panels; a visible CSS planet fallback when WebGL is unavailable or fails; responsive content sections that grow with their copy.

## Run / deploy

Use Node.js 22.12+ or 24. Run `npm ci`, then `npm run dev`. For Vercel select the Vite preset, build command `npm run build`, output directory `dist`. The archive also includes a prebuilt `dist` folder for static hosting. Serve through HTTP; do not double-click index.html.

## Scope / integration

This update addresses the requested content and visual changes. This remains a static React/Vite portfolio. The larger reference brief's PostgreSQL, authenticated CMS, CRUD APIs, media storage and admin analytics are not implemented. The original FormSubmit contact endpoint is retained and requires its owner's activation; email and phone links remain available. No live contact message was sent during checking. HUD flight figures are illustrative animation controls, not SEO performance claims.
