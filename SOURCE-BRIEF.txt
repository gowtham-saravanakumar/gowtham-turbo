Create an extreme, cinematic 3D portfolio website for a **Game Developer + Full Stack Developer**.

The website should NOT feel like a normal portfolio.

Build it as a **AAA sci-fi cinematic game experience** where the visitor travels through space, controls a cinematic camera, explores futuristic environments, and discovers the developer's portfolio through an interactive story.

Combine:

**Cinematic Sci-Fi Movie**
+
**AAA Sci-Fi Gaming**
+
**Spaceship Combat**
+
**Advanced WebGL 3D**
+
**Deep Parallax**
+
**Interactive Camera**
+
**Futuristic HUD**
+
**Cinematic Storytelling**
+
**Premium UI/UX**

Create an original sci-fi universe.

Do NOT copy Star Wars, Star Citizen, Halo, Mass Effect, Destiny, Cyberpunk, or any other copyrighted game/movie directly.
